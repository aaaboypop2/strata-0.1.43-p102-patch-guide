# ชุดตั้งค่า Strata แบบในคลิป (p102 / 4× P102-100)

ชุดนี้คือ Strata 0.1.43 กับแพตช์ คอนฟิก และเครื่องมือวัดผล แบบเดียวกับที่ใช้ทำคลิป
ใช้รัน Qwen3.8-Flash-Next บนการ์ดขุดเหรียญ P102-100 4 ใบ และบนเครื่อง RTX 3080 Ti + RTX 3060

## ใช้ยังไง

โยนทั้งโฟลเดอร์นี้ให้ AI agent ที่ทำงานบนเครื่องคุณ เช่น Claude Code, Codex หรือ OpenCode แล้วสั่งประมาณนี้

> อ่าน AGENTS.md ในโฟลเดอร์นี้ แล้วช่วยตั้ง Strata ให้เครื่องนี้ตามนั้น เครื่องผมมีการ์ด ... RAM ... GB

AI จะทำตามขั้นตอนใน `AGENTS.md`:

1. ลง Strata 0.1.43 แบบปกติก่อน และลองแชทให้ได้หนึ่งครั้ง
2. ใส่แพตช์ตามลำดับ
3. build engine ให้ตรงรุ่นการ์ด
4. ปรับคอนฟิก
5. วัดผลเทียบกับตัวเลขในคลิป

## ในโฟลเดอร์มีอะไร

| ที่ | คืออะไร |
|---|---|
| `AGENTS.md` | คู่มือสำหรับ AI (ภาษาอังกฤษ): ขั้นตอน สิ่งที่แพตช์แต่ละตัวทำ ค่าที่ควรตั้ง และบทเรียนเรื่องฮาร์ดแวร์ |
| `patches/engine/` | แพตช์ engine: พักแชทลง SSD, การ์ดว่างช่วยอ่าน prompt, CPU pool แยกต่อการ์ด |
| `patches/server/` | แพตช์ server: log ละเอียดขึ้น, สถิติต่อคำขอ, run id, โหมดปิดปรับปรุง |
| `configs/` | คอนฟิกจริงจากคลิป 3 ตัว (ลบ API key และชื่อเครื่องออกแล้ว) |
| `tools/` | `bench.py` วัดความเร็ว, `qualtest.py` วัดคุณภาพ, `build-engine.py` build engine, `maint.sh` |
| `results/RESULTS.md` | ตัวเลขทั้งหมด รวมผลทดสอบตอนเหลือการ์ด 1–3 ใบ |

## ข้อควรรู้

- **ใช้ได้กับ Strata 0.1.43 เท่านั้น:** เวอร์ชัน 0.2.x แพตช์บางส่วนลงไม่ได้ และต้นทางมีของใหม่ที่อาจทำให้แพตช์บางตัวไม่จำเป็นแล้ว
- **การ์ด Pascal ต้อง build ด้วย CUDA 12:** ได้แก่ P102, P104, GTX 10xx และ P40 เพราะ CUDA 13 ไม่รองรับการ์ดรุ่นนี้แล้ว
- **ระวังไดรเวอร์:** ตัวติดตั้ง CUDA อาจเปลี่ยนไดรเวอร์การ์ดจอไปด้วย ให้ AI ถามก่อนติดตั้งทุกครั้ง
- **RAM สำคัญกว่าจำนวนการ์ด:** IQ3_XXS ต้องใช้ RAM ราว 48 GB ถ้ามี 32 GB ให้ใช้ตัวที่เล็กกว่า
- **PSU:** P102 4 ใบกินไฟต่อเนื่องราว 1 kW และกระชากได้ถึงราว 1.45 kW ในคลิป PSU 1200W พังไปแล้ว
- **ถ้าเปิดให้เครื่องอื่นเข้า** (`host: 0.0.0.0`) ต้องตั้ง API key ทุกครั้ง
